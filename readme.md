## Projetos

### Barber Shop

Sistema completo para gerenciamento de uma barbearia, desenvolvido como projeto acadêmico e de portfólio.

O projeto envolve funcionalidades como:

- Cadastro e login
- Área do cliente
- Agendamento
- Cancelamento e reagendamento
- Notificações
- Atendimento por chatbot
- Transferência para atendimento humano
- Área administrativa
- Controle de usuários e agendamentos
- Banco de dados
- Autenticação

**Tecnologias:** React, TypeScript, Node.js, Express, PostgreSQL, Prisma, JWT e Socket.IO.
